# Siva Kumar Annam | Ultra-Modern Next-Gen Portfolio (v2.0)

> A futuristic Cyber-Glass portfolio engineered for **Siva Kumar Annam (Mr.A.S.K)**, Associate Software Engineer at MasterCom Technology Services (Client: **Tata Communications Ltd**).

## 🚀 Key Innovations & Never-Seen-Before Features

1. **At Least 2 Live High-Res Images Per Project with Deep Technical Breakdowns**:
   - Each project features verified production/architecture screenshots.
   - Click any image to open the **Fullscreen Technical Lightbox** with interactive zoom, tags, and architectural specifications.
2. **Interactive Real-Time Protocol Chatflows for EVERY Project**:
   - A visual, animated protocol simulation demonstrating exact component-to-component message exchanges (SNMP Traps, Python Netmiko SSH, BGP Flowspec, PostgreSQL CTEs, FAISS Cosine Similarity, SSE Tokens, Geocoding APIs, K8s Reconciliations).
   - Node-to-node packet visualization with latency badges, status codes, payload JSON inspectors, and step-through playback controls (Play / Pause / Next / Prev / 2x Speed / Reset).
3. **Interactive Architecture Labs**:
   - **SevOne NOC/SOC Incident Simulator**: Experience a live volumetric BGP spike trigger and see Python Netmiko runbooks remediate in under 4 seconds with ServiceNow SLA auto-closure.
   - **Interactive RAG Intelligence Studio**: Run semantic similarity queries against Siva's engineering background with 384-dimensional dense vectors and grounded citations.
   - **Real-Time Weather Microservice Tester**: Live meteorological forecast visualizer with rate limiting and in-memory TTL caching.
4. **Verified Recruiter CV Studio**:
   - Tailored 3-track CV hub for **Python Developer**, **DevOps & Cloud Engineer**, and **Network Automation Engineer** with instant downloads of verified PDFs.
5. **Interactive Developer CLI Terminal**:
   - Press `~` or click Terminal to interact with a bash emulator supporting `help`, `projects`, `sevone`, `rag`, `skills`, `resume`, `contact`.
6. **Tactile Web Audio API Synthesizer**:
   - Synthesized cyberpunk clicks and success chimes with an instant mute toggle.

## 🛠️ Tech Stack

- **Framework**: React 18 + TypeScript + Vite 6
- **Styling**: Tailwind CSS + Custom Cyber-Glass Theme
- **Icons**: Lucide Icons
- **Animation & Effects**: CSS Keyframes + Canvas Confetti + Web Audio API
- **Deployment Ready**: Zero-config static output in `dist/` with `vercel.json`
